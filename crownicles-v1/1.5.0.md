# 1.5.0

### Commandes ajoutées :

* `guildcreate <nom de guilde>` Permet de créer une guilde. Alias : `gcreate`.
* `guildleave` Permet de quitter une guilde. Alias : `gleave`.
* `guildadd <mention>` Permet d'ajouter un utilisateur à une guilde, nécessite d'être chef de guilde. Alias : `gadd` ou `ga`.
* `guildkick` Permet d'expulser un membre d'une guilde, nécessite d'être chef de guilde. Alias : `gkick`.
* `guild [nom de guilde ou mention]` Permet d'afficher les informations d'une guilde. Alias : `g`.
* `guilddaily` Permet de récupérer des récompenses de guilde. Alias : `gdaily` ou `gd`.

### Autres ajouts :

* Il est possible d'acheter de l'expérience de guilde au magasin.
* Il est possible de choisir son adversaire avec la commande `fight` en le mentionnant (par exemple `!f @joueur`).
* Ajout de 3 nouveaux événements.
* Mise à jour de la commande `help`.
* Il n'est plus possible d'acheter un soin des altérations d'état sans avoir d'altération d'état.
* L'apparence de certaines parties du magasin a été améliorée, et son code a reçu diverses petites améliorations.
* Le message indiquant le gain d'un objet mentionne désormais l'utilisateur concerné.
* Quelques changements divers ont été effectués sur les badges (voir #annonces).

### Correction de bugs :

* Correction d'un souci visuel sur le magasin en anglais.
* Le préfixe `"` n'était pas utilisable.
* Correction d'un bug d'affichage sur le message d'erreur anglais du tutoriel.
* Le lien de la commande `invite` était cassé.
